# 学習の設計

rinze の学習機能は「**文脈変換の良さを壊さずに、利用者の好みや固有名詞の選択を拾う**」ことを目的に設計している。

従来の IME のように「確定した語を無条件で先頭に固定する」方式では、ある文脈で選んだ語が別の文脈での変換を邪魔してしまう。rinze では zenz による文脈スコア（対数尤度）をベースにしつつ、控えめで追従性の高い加点方式を採用している。

## 学習のルール

- **選び直した候補だけを記録する**: 候補を送る・一覧から選ぶ・辞書登録するなどして「最初の候補以外」を確定したときだけ学習履歴に記録する。最初から 1 位に出ていた候補をそのまま確定しても記録しない。zenz がすでに当てている語を覚えてもその場での順位は変わらず、別の文脈で誤って引っ張られる副作用だけを生むためである。
- **見出しごとに最新の 1 件だけを加点する**: 同じ見出しについて、最後に選び直した候補 1 つだけに固定の加点を行う。選択回数でスコアを積み上げないため、過去に何度も選んだ語が過剰に強くなって文脈を押し潰すことがなく、別の候補を選び直せばすぐに切り替わる。
- **文脈の有無で加点の大きさを変える**:
  - **左文脈があるとき**: zenz の文脈スコアを尊重するため、加点は控えめにする。文脈的に明らかに別の語が自然な場合は zenz の判断が優先され、僅差の候補や固有名詞などでのみ学習が効く。
  - **左文脈が空のとき**: 行頭や入力欄の先頭では zenz に文脈の手がかりがないため、文脈ありのときより大きめに加点し、利用者が直前に選んだ語が出やすくなるようにする。
- **生成候補は学習対象外**: zenz が動的生成した候補は辞書エントリを持たないため、学習履歴には記録しない。繰り返し使いたい語は辞書登録することで候補と学習の対象になる。
- **abbrev と削除との連動**: zenz で並べ替えない abbrev では、最後に選び直した候補を先頭に昇格させる。また、`X` で候補を辞書から削除した場合は対応する学習履歴も同時に削除する。

## 履歴の保存と管理

学習履歴はタブ区切りの UTF-8 テキスト（見出し・候補・更新時刻）として保存される。既定の保存先は Linux で `$XDG_STATE_HOME/rinze/history.tsv`、macOS で `~/Library/Application Support/rinze/history.tsv` であり、`rinzed --history` で変更できる。`--no-learning` を指定すると学習の読み書きを完全に無効化できる。

書き込みはユーザー辞書と同じく `rinzed` のみが行い、ロック取得のうえで最新の内容をマージし、一時ファイル経由で原子的に差し替える。これにより、異常終了時の破損や別ソケットの `rinzed` との競合を防いでいる。また、1 位候補をそのまま確定する通常の打鍵ではディスク書き込みが発生しないため、入力の応答性を損なわずに同期書き込みを行えている。
