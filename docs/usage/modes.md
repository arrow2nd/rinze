# 入力モードとローマ字

## 入力モード

モードの切り替えキーと各モードの挙動は、ddskk の既定設定（JIS X 0201 半角カナ入力を有効にした状態）に揃えている。

| キー | ひらがな | カタカナ | 半角カナ | 全角英字 | ASCII |
| --- | --- | --- | --- | --- | --- |
| `q` | カタカナへ | ひらがなへ | ひらがなへ | `ｑ` を入力 | `q` を入力 |
| `C-q` | 半角カナへ | 半角カナへ | ひらがなへ | カタカナへ | 素通し |
| `l` | ASCII へ | ASCII へ | ASCII へ | `ｌ` を入力 | `l` を入力 |
| `L` | 全角英字へ | 全角英字へ | 全角英字へ | `Ｌ` を入力 | `L` を入力 |
| `C-j` | 入力途中を確定 | 入力途中を確定 | 入力途中を確定 | ひらがなへ | ひらがなへ |

### モード切り替えのルール

- **見出し入力中（▽）**: `q` は見出しをカタカナ（カタカナモードではひらがな、半角カナモードでは半角カナ）へ変換して確定し、`C-q` は半角カナへ変換して確定する。どちらも入力モード自体は変えない。`l` と `L` は見出しをそのまま確定してからモードを切り替える。
- **候補表示中（▼）**: 切り替えキーを押すと表示中の候補を確定してからモードを切り替える（候補一覧の表示中は `l` が選択キーとして優先される）。
- **ローマ字入力途中**: `q` `l` `L` がローマ字規則の続きになり得る場合（例: `zl` の `→`）はローマ字として解釈する。それ以外は保留中の `n` を「ん」に確定してから切り替える。
- **カタカナ・半角カナモードでの変換**: 大文字での見出し開始や変換、辞書登録はひらがなモードと同様に動作する。辞書検索と zenz への入力には常にひらがなの読みを使い、表示や無変換確定の文字種だけを現在のモードに合わせる。
- **ASCII モード**: `C-j` 以外のキーは rinze が処理せず、そのまま入力先へ渡す。
- **辞書登録中の独立したモード**: 辞書登録の入力欄は外側とは独立したモードを持ち、常にひらがなモードで始まる。登録を確定または中断すると外側のモードへ戻る。

## ローマ字規則（ddskk との違い）

ローマ字変換規則は ddskk の既定テーブルに準拠しており、`z` 始まりの記号（`z ` の全角空白、`z*` の `※`、`zL` の `⇒` など）や撥音の扱いも同じである。現代的な日本語入力と整合させるため、以下の点だけ ddskk の既定から調整している。

- **全角記号の扱い**: ひらがな・カタカナモードでは `!` を「！」、`~` を「〜」（U+301C）として入力する。日本語の文章中では全角で打つ頻度が高いためである。半角カナモードではそのまま半角で入力する。
- **Unicode の現代的な仮名**: ひらがなモードでは `va` 等を濁点分離ではなく「ゔぁ」、`xka` / `xke` を「ゕ」「ゖ」として出力する。
- **Emacs 固有コマンドの除外**: ddskk で Emacs 関数を呼び出す `@`、`$`、`\` などは特別な処理を行わず、記号としてそのまま入力する。
