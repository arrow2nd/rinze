# macOS

macOS 環境では InputMethodKit ベースの入力メソッド（`rinze.app`）として rinze を利用できる。Neovim と同じ `rinzed` を共有し、システム全体の入力欄で左文脈を活かした変換が行える。

導入手順は [macOS で入れる](../install/macos.md)、テストは [macOS のテスト](../development/testing.md#macos) を参照。

## 構成と責務分担

アプリ（`macos/`）は Swift で実装し、InputMethodKit との連携およびパネル・メニュー表示のみを担当する。`rinzed` との通信、応答の解釈、デーモンの自動起動、左文脈の整形は [fcitx5 アドオン](fcitx5.md)と共通の Rust クレート `rinze-client` に集約し、静的リンクの C ABI 経由で呼び出している。Xcode プロジェクトは持たず、`swiftc` で直接ビルドするシンプルな構成としている。

## 挙動と設計方針

基本的な[打ち方](../usage/typing.md)は Neovim や fcitx5 と共通であり、macOS 固有の環境に合わせて以下の方針をとっている。

- **入力ソースとモード管理**: 入力ソースは `rinze` 1 つとし、メニューバーのアイコンは固定のまま、入力モード（`かな` / `カナ` / `ｶﾅ` / `全英` / `aA`）を入力欄ごとに管理する。新しい入力欄は ASCII モード（`aA`）で始まり、`C-j` でかな入力へ切り替える。モード切り替え時にはカーソル下に短時間ラベルを表示する。
- **直接入力アプリの除外**: メニューバーの入力メニューから「このアプリで直接入力」を選ぶと、対象アプリ（バンドル ID で識別）では `C-j` を含めすべての打鍵をそのまま渡す。設定は `defaults` に保存され再起動後も維持される。
- **表示と操作**: 未確定文字列は下線付きでインライン表示し、候補一覧・辞書登録・削除確認・エラー通知はカーソル下のパネルに表示する。候補一覧では `x` / Space に加えて Up / Down でもページ送りできる。
- **フォーカス喪失と確定**: 入力欄からフォーカスが外れたときは未確定文字列を確定せずに破棄し、学習履歴にも残さず ASCII モードへ戻す。入力ソースを切り替えたときやアプリから確定を求められたときは表示どおりに確定する。
- **左文脈の取得**: 入力欄からカーソル直前のテキストを取得して `rinze-client` 経由で `rinzed` へ送る。取得できないアプリでは空の左文脈として扱う。パスワード欄では macOS 側が入力メソッドを自動的に無効化するため、打鍵は rinze に届かない。

## rinzed の起動と探索順

起動や応答タイムアウト時の振る舞いは `rinze-client` が受け持つため、[fcitx5 と同じ](fcitx5.md#rinzed-の起動と応答待ち)である。ただし macOS の入力メソッドプロセスにはユーザーのシェル設定の PATH が引き継がれないため、自動起動する `rinzed` は以下の優先順で探索する。

1. `defaults` の `rinzed` キー
2. `Info.plist` の `RinzedPath`（Nix パッケージやビルドスクリプトが埋め込むパス）
3. プロセスの PATH 上の `rinzed`

[rinzed を常駐させて](../install/flake.md#rinzed-を常駐させる)おけば、アプリは既存ソケットへ接続するだけで自前起動は行わない。

## 設定と診断

設定は `defaults`（ドメイン `io.github.arrow2nd.inputmethod.rinze`）で管理する。`directApps` 以外の変更は `pkill -x rinze` で再起動すると反映される。

| キー | 意味 |
| --- | --- |
| `socket` | 接続先ソケットのパス（未指定時は既定ソケット） |
| `rinzed` | 自動起動する `rinzed` のパス |
| `directApps` | 直接入力にするアプリのバンドル ID の配列（入力メニューからも更新可能） |
| `debug` | 打鍵ごとに左文脈の取得状況と内容をパネルに表示する（真偽値） |

接続エラーなどのログは `NSLog` に出力されるため、`log stream --predicate 'process == "rinze"'` で確認できる。
