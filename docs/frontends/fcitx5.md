# fcitx5

Linux 環境では fcitx5 の入力メソッドとして rinze を利用できる。Neovim と同じ `rinzed` に接続して変換するため、ユーザー辞書や学習履歴をシステム全体で共有できる。

導入手順は [fcitx5 で入れる](../install/fcitx5.md)、軽量化の方針は [ネイティブフロントエンドの軽量化](../architecture/performance.md#ネイティブフロントエンドの軽量化)、自動テストは [fcitx5 のテスト](../development/testing.md#fcitx5) を参照。

## 構成と責務分担

fcitx5 アドオン（`fcitx5/`）は C++ で実装し、fcitx5 フレームワークとの連携と UI 表示のみを受け持つ。`rinzed` との通信、応答の解釈、デーモンの自動起動、左文脈の整形といったロジックは Rust の `rinze-client` に集約し、静的リンクの C ABI 経由で呼び出している。

## 挙動と設計方針

基本的な[打ち方](../usage/typing.md)は Neovim と共通であり、デスクトップ IME として以下の配慮を行っている。

- **入力欄ごとの状態分離**: 接続は入力コンテキストごとに独立して作成し、入力欄が閉じられると接続も閉じる。rinze を有効にした入力欄以外では接続も `rinzed` の起動も行わない。
- **機密入力と直接入力アプリの除外**: パスワード欄や機密入力欄では打鍵を横取りせずアプリへそのまま渡し、学習履歴にも残さない。また、トレイメニューの「このアプリで直接入力」を使うと、ターミナル上の Neovim など OS 側 IME を介したくないアプリを永続的に除外できる（既定の保存先は `~/.config/fcitx5/rinze/direct-programs`）。
- **フォーカス喪失と初期モードの扱い**: 新しい入力欄は ASCII モード（`aA`）で始まり、`C-j` でかな入力へ切り替える。入力欄からフォーカスが外れたときは、未確定文字列を確定せずに破棄し、学習履歴にも残さず ASCII モードへ戻す。アプリからリセットされたときは未確定文字列のみ破棄してモードを維持し、入力メソッド自体を切り替えたときは表示どおりに確定する。
- **候補一覧と表示**: 未確定文字列は対応アプリではインライン表示し、非対応アプリではパネルに表示する。候補一覧・辞書登録・削除確認はパネルに表示し、`x` / Space に加えて fcitx5 のページ送りキーやクリック操作にも対応している。

## rinzed の起動と応答待ち

`rinzed` が起動していない状態で rinze が有効になると、アドオンはバックグラウンドで `rinzed` を起動し、待ち受け開始までの間はパネルに状態を表示しつつ打鍵をアプリへそのまま通す。起動に失敗した場合は原因をパネルに表示し、一定時間後に再試行する。

打鍵ごとの応答待ちでは、一時的な高負荷による遅延にも耐えられるよう長めのタイムアウトを設けている。万一タイムアウトしても未確定状態をすぐには捨てず、次の打鍵で遅れた応答の回収を試みる。応答が完全に途絶えたとみなした場合は接続を破棄してアプリへ打鍵を通し、復旧するまで短いタイムアウトに切り替えることで、ハングしたデーモンによって入力全体が固まり続けるのを防いでいる。

## 左文脈の取得

入力欄から surrounding text を取得し、カーソル直前の文字列を左文脈として `rinzed` へ送る。surrounding text を提供しないアプリでは空の左文脈を送り、文脈なしの順で候補を並べる。

Firefox のように未確定文字列を含んだ surrounding text を返すアプリに対しては、表示中の未確定文字列と照合して該当部分を取り除いたうえで文脈として利用する（本文に書かれた `▽` や `▼` は誤って消さないよう位置関係を見て判定する）。

## 診断と環境変数

`RINZE_FCITX_DEBUG=1` を指定して `fcitx5 -r --verbose=rinze=5` を起動すると、打鍵ごとに左文脈の取得状況と送った文字列をパネルとログへ出力する。通常時はプライバシー保護のため打鍵内容をログに出さない。

| 環境変数 | 意味 |
| --- | --- |
| `RINZE_SOCKET` | 接続先ソケットのパス（未指定時は既定ソケット） |
| `RINZE_RINZED` | 自動起動する `rinzed` のパス（未指定時は PATH から探索） |
| `RINZE_FCITX_DEBUG` | 左文脈の診断出力を有効にする |
| `RINZE_DIRECT_PROGRAMS` | 直接入力アプリ一覧の保存先ファイル |
