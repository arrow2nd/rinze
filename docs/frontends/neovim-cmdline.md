# Neovim のコマンドライン

`/` `?` による検索や `:` のコマンドラインでも rinze を利用できる。コマンドラインは開くたびに無効状態で始まり、`enable` を呼んだときだけそのコマンドラインを抜けるまで有効になる。

```lua
vim.keymap.set('c', '<C-j>', function() require('rinze').enable() end)
```

`enable` / `disable` / `toggle` および `preedit()` / `mode()` / `status()` は現在のモードを判別するため、挿入モードと同じ関数をコマンドラインモードでもそのまま使える。

## 設計の方針

- **挿入モードからの状態分離**: コマンドラインでは挿入モードとは別の接続を使い、常にひらがなモードで始まる。コマンドラインでの操作が挿入モードの有効状態や入力モード、未確定の見出しに影響することはない。コマンドライン中にフォーカスを失ったときは未確定文字列を確定して ASCII モードへ戻り、Esc や `C-c` で抜けた場合は未確定文字列を破棄して接続を閉じるため、履歴やバッファにゴミが残らない。
- **フロートウィンドウによる未確定表示**: 未確定文字列はコマンドライン本体には挿入せず、カーソル位置に重ねたフロートウィンドウで描画する。コマンドラインへ直接挿入する方式だと、見出し入力中の `▽` に `incsearch` や `inccommand` が反応して画面が意図せず戻ったり、中断時に未確定文字列が履歴へ残ったりする問題があるためである。フロート表示により、検索ハイライトは確定済みの文字列だけで安定して動作する。
- **コマンド構文を除いた左文脈**: コマンドラインの文字列から、最後の ASCII 記号や空白より後ろだけを左文脈として `rinzed` に渡す（例: `:%s/明日は雨/あした` なら `あした`）。コマンドの構文を日本語の文脈としてモデルに渡さないことで、検索 `/` の直後や `:s/` の直後を行頭と同じ条件で扱えるようにしている。
- **blink.cmp のコマンドライン補完との調整**: コマンドラインでかな系または全角英字モードが有効な間は、候補一覧と補完メニューが重ならないよう blink.cmp のコマンドライン補完を一時的に停止し、ASCII モードへ切り替えるかコマンドラインを抜けると元の設定へ戻す。
